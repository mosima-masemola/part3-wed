 BestiesBakes Bakery Website

 1. Project Overview

BestiesBakes is a bakery website developed to showcase a variety of cakes, cupcakes and freshly baked pastries. The website provides customers with information about the bakery, its products, services and contact details.

The website is designed to give customers a simple and user-friendly experience when exploring bakery products and making order enquiries.

 2. Project Objectives

- Create an attractive and user-friendly bakery website.
- Display bakery products and services.
- Provide information about the bakery and its team.
- Allow customers to submit online order requests.
- Make it easier for customers to contact the bakery.

 3. Website Features

Home Page
Introduces BestiesBakes and displays bakery images, featured products, customer reviews and special offers.

 About Us Page
Provides information about the bakery's background, team members, core values and achievements.

 Products Page
Showcases the different cakes, cupcakes and pastries offered by the bakery.

Online Ordering Page
Allows customers to provide their details and submit cake or pastry order requests. Customers can specify their preferred products and ordering requirements.

 Contact Page
Provides the bakery's contact information, business hours, location, Google Maps display and a contact form for customer enquiries.

 4. Technologies Used

- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used to style the website, including colours, layouts, backgrounds and fonts.
- **Font Awesome:** Used to display icons throughout the website.

 5. Project Structure

The project is organised into the following folders and files:

- `index.html` – Home page.
- `about.html` – About Us page.
- `products.html` – Products page.
- `order.html` – Online ordering page.
- `contact.html` – Contact page.
- `css/style.css` – Website styling.
- `images/` – Contains website images and logos.
- `js/script.js` – JavaScript file, if used.

 6. How to Run the Project

1. Download or clone the repository from GitHub.
2. Extract the project folder if downloaded as a ZIP file.
3. Open the project folder in Visual Studio Code.
4. Locate the `index.html` file.
5. Open it in a web browser to view the website.

7. Online Ordering Functionality

The online ordering section is designed to collect customer information and order requests. Customers can provide their details and specify what they would like to order.

Please note that the website does not currently include a confirmed automated payment or online checkout system.

 8. Project Purpose

This project was developed as part of a web development assignment to demonstrate the use of HTML and CSS in creating a multi-page bakery website.
